# Development Workspace

Эта папка предназначена для основной рабочей деятельности вокруг проекта, которая не должна засорять корень репозитория.

## Назначение

Сюда складываются:

- заметки по серьёзным изменениям
- временные скрипты и одноразовые инструменты
- промежуточные логи
- рабочие отчёты
- черновые артефакты разработки

## Структура

- [`changes/`](/D:/Development%20GPTMEAi/development/changes)
  история серьёзных изменений
- [`logs/`](/D:/Development%20GPTMEAi/development/logs)
  рабочие логи разработки
- [`tmp/`](/D:/Development%20GPTMEAi/development/tmp)
  временные артефакты
- [`scripts/`](/D:/Development%20GPTMEAi/development/scripts)
  временные и служебные скрипты, не являющиеся частью official runtime

## Правило

Новые временные материалы по умолчанию должны создаваться здесь, а не в корне проекта.

Для служебных операций разработки по умолчанию предпочтительны project-local Python-скрипты в [`development/scripts/`](/D:/Development%20GPTMEAi/development/scripts), а не одноразовые shell-команды.

Исключения:

- официальный runtime
- постоянная архитектурная документация
- постоянные data/runtime файлы

## Переходный статус

Корень проекта всё ещё содержит исторические временные скрипты и логи. Они не были автоматически перенесены сюда, чтобы не сломать старые workflow.

Очистка корня должна происходить постепенно и осознанно.
