# Contributing to GPTMEAi

This repository is **private and proprietary** — see [NOTICE](NOTICE). Contributions
are accepted only from authorized collaborators. Participation is governed by the
[Community Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting and proposing

- Use a **bug report** for a concrete, reproducible problem: what you ran, the
  environment, the observed result, and the expected one.
- Use a **change proposal** for a new capability or a substantial change: the
  scenario, the current gap, and the outcome that would show it works.
- Keep unrelated changes out of the same pull request.

## Before opening a pull request

- The scenario and the desired result are clear.
- The repository's checks were run (see the README) and the results are recorded.
- Behavioral evidence is described honestly, including what was not verified.
- The diff contains no secrets, credentials, or unrelated churn.
