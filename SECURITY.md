# Security Policy

This is a **private repository**. Access is limited to authorized collaborators.

## Reporting a vulnerability

Report vulnerabilities directly to the repository owner through their
[GitHub profile](https://github.com/Alpha-Oi), or open a private security advisory from
the repository's **Security** tab (**Advisories** → **Report a vulnerability**).

Do not open a normal issue for a vulnerability. Include the affected component, the
commit, a minimal reproduction, expected and observed behavior, impact, and any
proposed mitigation.

## Supported versions

Only the current `main` branch is maintained.
